# loveur.website

Static one-page info site for Fred Ramon's quick Wix websites for small businesses in Southwest Ranches, Davie, and the surrounding areas.

- `index.html` is the whole site (no build step, no JavaScript).
- Contact details are placeholders (`FRED_PHONE_PLACEHOLDER`, `FRED_EMAIL_PLACEHOLDER`) until Fred supplies them.
- The custom domain (`CNAME` file) is intentionally not added yet.
